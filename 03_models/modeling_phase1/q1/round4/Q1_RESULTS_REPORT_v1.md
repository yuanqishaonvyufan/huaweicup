## R1. 全 22 项画像与可定向五维表示

**数值：**A1/A2/A3 共 272,505 物理记录、261,086 不同 ID；全 22 项均在[域画像](Q1_FULL22_DOMAIN_PROFILE_v1.csv)保留角色和分位数，主描述向量只由五项有方向依据的信号构成。此前五核心 PCA 首维只解释 48.11%，DQ2 pooled 两组仅在 3/9 域/扩展层复现；语义性质量冲突确认数 **0**。[角色表](Q1_FULL22_ROLE_MAP_v1.csv)为 5 CORE、2 SECONDARY、12 SENSITIVITY、1 UNKNOWN、2 REDUNDANT。

**解释：**单一评分会遮蔽无广告等弱共变信息；DSIR 三列近重复且强受长度关联，不能当三个独立质量维度。当前“冲突”证据主要是统计分歧、域差、冗余及尺度候选，故保持多维画像；DQ0 仅是五项等权分位的透明摘要。

**验证：**A1 arxiv 五 CORE 的平均相对分位约 `0.840/0.752/0.690/0.865/0.807`，A2 非重叠扩展约 `0.834/0.748/0.682/0.864/0.806`；A1 github 约 `0.439/0.277/0.512/0.163/0.257`，A3 非重叠扩展约 `0.440/0.277/0.515/0.162/0.258`。抽样与扩展方向一致，但源同为同一标注体系，不能冒充独立训练干预。逐域 n、分位和描述性 SE 见[核心域画像](Q1_CORE_DOMAIN_QUALITY_PROFILE_v1.csv)。另以 A1 原文做[七域 14 案例的定向面效度检查](../../../../01_data/audits/modeling_phase1/q1/Q1_CONTENT_FACE_VALIDITY_R4_v1.md)：新闻/广告等部分排序具直观一致性，但代码与非英文条目出现用途/语言反例，不能称独立人工准确率。

**限制与含义：**A1 book 仅 171 行，A2 的 argmax 编码敏感；17 项未有通用方向。英语评级可能惩罚可用代码或非英文文本；五维只作描述，不能传为 Q2 可识别 `γ_Q`。完整 Q1 评分的题面措辞须连同这些限制呈现，不把 Full-22 与五维向量混为一物。

## R2. 17 域配比确有 1M 留出预测信息

**数值：**在 A7/1M 的 256 个真实留出运行，M1 的 R0 RMSE **0.2278**，M0 为 **0.2846**；13 域平均 RMSE **0.4540** 对 **0.7129**。M1 相对 M0 的 R0 MSE 成对 bootstrap 差为 `−0.02913`，95% bootstrap 分位区间 `[-0.03949,-0.01893]`；平均逐域标准化 MSE 差为 `−0.5804`，区间 `[-0.6276,-0.5359]`。13/13 域 RMSE 均下降，但最弱域仍有误差。[模型比较](P_RESPONSE_MODEL_COMPARISON_v1.md)

**解释：**合法 16 自由坐标的 M1 在 1M 附件内捕获了比不看 p 的均值基线更有用的配比—Loss 关联。M2 α=0.01 的微小差异没有稳定验证收益，M3 的训练升级条件未触发；因此按停止规则选 M1，而非追求更复杂拟合。

**验证：**五折训练分数 M0/M1/M2 为 `1.0016/0.7504/0.7497`；A7 上 M2 对 M1 的 R0/逐域 MSE 差 bootstrap 区间均跨零。A7 M1 的 R0 运行秩相关约 **0.624**，显示有预测信息但排序远未完美。

**限制与含义：**这是观察到的 512 配方与 256 留出配方上的预测关联，不是单域的因果替代弹性。13 域必须按 [R3 逐域表](P_RESPONSE_DOMAIN_VALIDATION_v2.csv)并行展示，不能用平均误差遮蔽领域失败。

## R3. 规模迁移和 p 支持边界

**数值：**相同 A6/A8 配比在 A9/60M 上，M1 的中心化 R0 RMSE 为 M0 的 **0.888**、平均逐域中心化 RMSE 为 **0.677**；A11/1B 分别恶化到 **3.108** 和 **1.967**。A6/A8 完全相同，不能视作独立 p 验证。1M 只有 **2/256** 个配比落在训练观测凸包内，252 为按训练近邻定义的 NEAR，2 为 OUT。[支持域证据](P_FEASIBLE_REGION_EVIDENCE_v1.md)

**解释：**60M 保留部分配比相对形状；1B 即使有更多凸包内点仍失效，模型规模效应不能仅用 p 距离解释。经验凸包过窄，单域 min/max 又过宽；近邻局部扩展只可作为后续支持约束候选。

**验证：**每行支持标签先按 A4 训练几何固定，真实 A6–A11 Loss 只用于分层验收；1B 的 64 行中心化失效为观察结论，不用未知规模偏移回拟参数。

**限制与含义：**不能把 1M 模型写成 1B 绝对 Loss 预测器，也不能给 Q3 定最终 full-simplex 最优域。远离支持区的样本极少，域外误差斜率仍不确定。后续需单独建规模迁移机制并再留出验证。
