# P1-1 13-domain Loss response comparison preregistration final v1

**STATUS: PREREGISTERED — AWAITING MODEL COMPARISON.** 本文件是 Modeling Phase 1 的正式使用前响应比较合同，继承已获 Gate 1 确认的 [P1-1 v1.1](../../../01_data/audits/phase1/P1_1_13_DOMAIN_RESPONSE_PREREG_v1_1.md)，不改 R0–R3 编号，不预选最终赢家，也不定义最终 Q1 数学模型。来源为 [ACTIVE Gate 1 共识](../../../02_analysis/consensus/GATE1_CONSENSUS_v1.md)的 §4、§9 与 Phase 1 v2 的 AUDIT-04。使用 A6–A11 Loss 选择响应或模型前，本合同及任何训练内选择必须冻结；修订另立版本并记录理由。

## 共同输入、单位与数据角色

令训练运行 `r` 对应 A4/A5 的唯一 `index`，`L[r,m]` 是 A5 中第 `m=1,…,13` 个 `metric/the_pile_*_val_loss` 原始列，具体顺序固定为 [审计指标 JSON](../../../01_data/audits/phase1/route_audit_metrics.json) 中 `A.A4_A5.loss_columns`。这些列均为验证交叉熵 Loss，方向为**越低越好**；记录文件未独立证实对数底数和 Tokenizer 的详细口径，故单位写“原表交叉熵 Loss 单位”，不得擅称与 B1 绝对同标尺。A5 训练 512 行的 13 列无缺失；A7/A9/A11 只作对应 A6/A8/A10 的预留检验，A12–A15 是估算外推。

| ID | 输入与数学定义 | 标准化/单位 | 优点 | 主要风险 | 比较指标与保留/淘汰规则 |
|---|---|---|---|---|---|
| **R0** | `R0[r] = (1/13) Σ_m L[r,m]`；13 域固定等权 | 不标准化；原表 Loss 单位 | 透明、可解释、可作统一基线 | 域波动不同，均值可能掩盖冲突或被高变异域主导；等权不是实际用途权 | 训练内检查单域贡献、leave-one-domain-out 排序/波动与 R3 冲突。无外部用途权依据时保留为最透明 **PRIMARY RESPONSE BASELINE CANDIDATE**；即使不作最后主叙事也保留对照。若对已支持的 p 变化出现可信聚合改善而关键域恶化，不能单独用 R0 作结论。 |
| **R1** | `z[r,m]=(L[r,m]-μ_m)/s_m`，`R1[r]=(1/13)Σ_m z[r,m]`，`μ_m,s_m` 只由 A5 训练行估计并冻结 | 训练内标准化；无量纲 | 检查不同域波动尺度对综合结论的影响 | 小方差域及测量噪声会被放大；不能不校准就作为 Q2/B1 绝对 Loss | 比较领域贡献、训练运行重抽样稳定性及与 R0/R3 的方向一致性。若某训练域 `s_m=0` 则标该候选不可用，不临时加常数；若不稳定或失去实用解释，仅保留敏感性，不升主响应。 |
| **R2** | 对 A5 的 `z` 矩阵求第一主成分，`R2[r]=Σ_m w_m z[r,m]`；载荷 `w_m` 与符号只由 A5 确定，符号固定为与 R0 正相关 | 训练内 z 后 PCA；无量纲 | 检验共同因子是否有解释力 | Phase 1 训练 PC1 只解释约 22.8%，且 24/78 域对负相关；载荷可能不稳定或抹平冲突 | 比较以运行重抽样所得载荷/排序稳定性、正负载荷和域覆盖。若载荷方向/解释不稳定或主要由少数域驱动，淘汰“主响应”用途；仍可报告结构诊断。未经独立用途依据不得仅凭训练拟合优于 R0 宣布胜出。 |
| **R3** | `R3[r]=(L[r,1],…,L[r,13])`；13 域逐项分析及同一 p 变化的域别对照 | 不标准化；各分量保留原表 Loss 单位 | 揭示领域异质、受损域与冲突 | 模型与叙事复杂度增加 | **强制保留**，不得因任何综合候选表现好而删除；报告域别方向、误差、不确定性与最差受损域。综合响应不能给稳定且不遮蔽的结论时，R3 升为多响应/多目标主叙事。 |

## 比较与冻结规则

1. **冻结的是规则，不是赢家。**在 A5 训练数据内、接触 A6–A11 留出 Loss 以选模型之前，比较 R0/R1/R2 的解释性、以配方运行为单位的重抽样稳定性、13 域覆盖、单域主导风险、与 R3 冲突的程度及跨训练子样本稳定性。R3 始终并行。
2. 不用不同单位的 R0/R1/R2 原始 RMSE 直接排名；比较预测时须先统一评价目标/尺度，并同时报逐域误差。权重、均值、标准差、PCA 载荷只在 A5 学得且应用留出时冻结。无充分理由改权时，R0 是透明默认**报告基线**，不因此成为已确认最终主响应。
3. 对同一可行 p 扰动，若综合改善但某域可信恶化，必须显示冲突、最差域与不确定性。选择依据不得只靠训练拟合最好、PCA 解释率单值或无来源固定阈值。
4. A6/A8 配比相同但模型规模不同，不重复计作独立 p 支持；未来 A6–A11 验证至少报告响应/逐域 MAE、RMSE、相对训练均值基线、域别效果符号、残差、凸包内外与规模分层。A12–A15 的估算 Loss 不作真实外推真值。
5. 候选最终选择必须写 `Q1_RESPONSE_SELECTION_REPORT_v1.md`，带 Experiment ID、输入/预处理/响应版本与对 R3 的检查；选择后仍须过 Gate 2 才可进入 Q2。P1-1 只达 **PREREGISTERED — AWAITING MODEL COMPARISON**，不是 `RESOLVED FINAL RESPONSE`。
