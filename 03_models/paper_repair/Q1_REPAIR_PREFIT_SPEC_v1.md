# Q1 题意补足计算合同

本补充只读 Round3 冻结质量特征和 Round4 已冻结 M1；不修改 Q1 旧训练、留出结果。新增 `Q_full` 为按明确用途规则构造的 **22 项评分 rubric**，不是数据识别出的真实潜在质量，也不自动成为 Q2 的独立质量效应。原有五维画像和 DQ0 保持独立解释层。

1. 参考样本仍为 A1 按既有 SHA256 ID 规则分出的训练 ID。每个有效原值作中秩经验分位。列表类沿用冻结标量编码；QuRating 四个原分量分别计算分位效用，再平均为第 10 项。计数字段先 `log1p`，异常 n-gram 原值不裁剪。
2. 五个有明确正向含义的核心信号以较高分位为较高效用。其余 17 项没有证实的通用单调质量方向：在 A1 训练部分的五核心 DQ0 最高 20% 文本中，取各信号的中位参考分位 `t_j`，定义 `u_j=1-|F_j(x)-t_j|`。这是“与已声明的高核心参考画像接近”的双侧评价约定，非该信号越大越好之经验发现。对 DSIR 只使用此相对参考含义，不声称已恢复负原值的确切量尺；长度和字符规则仍保留用途依赖。全部处理后的 22 个效用都满足在本 rubric 中“越接近指定目标越高分”。
3. 缺失效用填入中性值0.5，并报告每行22项覆盖数及逐项缺失；不把填补当独立测量。等权 W0：22效用平均。冗余敏感性 W1：以 A1 训练各效用的绝对 Spearman 相关，`w_j∝[1+Σ_{k≠j}max(0,|ρ_jk|-0.5)]^-1`，归一化后加权；该权重不读 Loss。W0固定为正式可解释评分，W1及既有DQ0作稳定性检查，不按结果大小重选方案。
4. 输出所有272505条物理记录的 `Q_full_W0`, `Q_full_W1`, `DQ0`, 覆盖数；A1七域、A2 arxiv、A3 github以及去除A1重复 ID 的扩展集，报告均值、百分位、样本自助抽样均值区间与排序。重抽样只表示当前来源内的样本组成敏感性，不是独立人类质量标签准确率。
5. A12/A13 是10B估算配比/Loss、A14/A15是70B估算配比/Loss，各自仅按 index 一对一连接，核原件哈希与17项单纯形。用原冻结 M0/M1 在每组计算 R0 及13域；跨规模只报告中心化形状 RMSE 比、秩相关、预测方向一致率、支持距离与凸包。不得回拟或由估算表升级 M1。仍以 A11/1B真实留出失败为较强证据。

在得到数值前，本规格不预先设定哪个领域排序或外推结果“应当”出现。若范围内的任一指标缺损使22项评分不能可靠计算，应如实降级完成度，不填造数值。
