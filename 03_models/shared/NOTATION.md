# 研究设计阶段术语与符号

状态：ROUND 5 统一口径；仅定义含义，不代表模型已选定或参数已估计。具体单位与取值范围须在数据审计后写入版本化模型规格。

| 记号/词 | 当前统一含义 | 类型 |
|---|---|---|
| p | 17 个训练领域所占比例，非负且分量和为 1；“配比”专指这个向量 | 观测设计；Q3 可为候选决策量 |
| 配方/运行 r | A4/A5 等按 index 配对的一次配比实验及其 Loss；不同于“配比”向量概念 | 观测单位 |
| q | 质量域或映射后训练域的质量向量，保留映射等级与不确定性 | 构造测量 |
| Q_r | 若存在，某一配方/运行同粒度的总体质量指标；未证实 A4/A5 具有该字段 | 待审计构造量 |
| Q_eff | 由 p 与 q 构造的有效质量候选，例如 pᵀq；不能据构造列宣称独立质量实验 | 候选构造量 |
| N、D | 参数个数、训练 Token 个数；B 表中的十亿单位须先换成原始个数 | 观测输入；Q3 候选决策量 |
| C、C_train、C_Q、C_attn | 总预算及训练、质量、注意力代理成本，统一 FLOPs | 约束/成本 |
| L_ctx | 上下文窗口长度，按 C7 给外生可行情景 | 外生量，非内点决策 |
| L / Loss | 验证集交叉熵；A 有 13 个验证域列，主响应尚未冻结 | 观测响应或模型预测 |
| X_p / P_c | p 经合法单纯形对比得到的设计块；常配截距，用于秩诊断 | 构造设计矩阵 |
| X_q、X_full | 质量设计块及与规模/配比块合并后的同运行完整设计；不能跨源拼伪行 | 构造设计矩阵 |
| γ、α、β | 候选质量、参数/数据规模效应参数；符号及证据性质随模型版本明确 | 未估参数 |

状态标签：CONFIRMED FACT 指题面/数据说明可见事实；WORKING HYPOTHESIS、CANDIDATE、DATA_AUDIT_REQUIRED、OPEN、REJECTED 用于研究设计；CLOSED — DESIGN LEVEL 仅表示审计决策路径已具备，不能写成“经验识别通过”。文件命名按已保存的 Round 1–5 版本递进，不覆盖 v1 原稿。
