# figure-generator

## When to use
Use for data, model, validation or result visuals once source data and result IDs exist.

## Inputs
Read FIGURE_REGISTRY.md, RESULTS_REGISTRY.md and underlying checked data.

## Work
Choose a plot based on the argument and data structure; label axes, units and uncertainty. Generate through 04_code/visualization/ or an editable diagram source. Verify final rendered size and avoid decorative or fictitious result graphics.

## Output
Figure file, generation script/config, purpose, interpretation and Figure ID. Formal paper figures should point to VALIDATED results.
