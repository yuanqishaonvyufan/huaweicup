# delivery-audit

## When to use
Use only when a final Word/LaTeX/PDF/HTML or support package exists.

## Inputs
Read official format/template and submission manual, PAPER_STATE.md, result/figure registries and the actual delivery files.

## Work
Check openability, cover/template, abstract and page numbering, no identity outside cover, typography, citations, figure readability, code/result attachment completeness, paths, file size and final PDF MD5 identity. Distinguish official requirements from internal quality targets.

## Output
A dated final_check report listing pass/fail evidence and remaining blockers; do not claim submission or acceptance from a local audit.
