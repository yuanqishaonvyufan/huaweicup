# 1 Executive Synthesis

共同主线仍是“质量与领域结构 → 条件损失关系 → 算力配置 → 历史能力与前沿”，但需要把“条件”写进每一条连接。双方一致认为 Q_eff 与 p 的可识别性、A/B Loss 运输、半合成证据、C7 可行上下文和 Loss–Benchmark 桥接是决定路线的门槛。Opus 对审计优先级、Q1 层级、Q2 逐级复杂化和 Q4 强/弱/无桥接情景的补充有价值；其若干具体阈值、参考域和预算/成本解释尚无依据或可被反证，已在下文修正。

**CONFIRMED FACT（来自题面/可见数据说明）**：Q1 使用 A1–A3 全量质量信号、A4–A15 配比表，其中 A6–A11 留作检验、A12–A15 是外推/估算；17 个训练域配比对应 13 个验证域 Loss；Q2 B1 为主要拟合、B6–B8 为半合成；Q3 的 L_ctx 外生、成本代理含 6ND 与 ηNDL_ctx，η=2×10⁻⁴，题面建议预算 10¹⁹、10²²、10²⁴ FLOPs 或至少三个不同量级；Q4 必用 C8 逐任务分析且桥接按可比性分层。题面没有指定 Q1 的 13 域综合 Loss 权重，也没有指定单一最终模型。

**阶段结论**：先做可使路线分叉的 P0 数据审计。即使之后证明 Q 与 p 不能单独估，Q1 的测量和配比响应、Q2 的条件广义关系、Q3 的预算配置仍可推进，但独立“质量弹性/等效参数量”必须降为假设驱动情景或界限；Q4 若无可靠桥接，应作为有自身识别与验证的现实能力演化研究，不能称 Q3 的外部验证。

    A6–A11 真实留出 / A12–A15 估算外推 ────────────────┘   ↑ B1 主拟合，B2/B3 与 B4/B5 分级核验，B6–B8 情景

    附录 B 成本 + C7 外生上下文 → Q3 预算配置/转移 ────⇢ Q4 能力情景（Strong/Weak/No Bridge）

Q1 的质量测量可独立完成，但从质量域 q 到每个配方运行的 Q_r 不天然存在；Q2 的 B1 也没有观测配比 p 的变化。Q3 只可消费 Q2 已标明有效范围的关系。Q4 的历史贡献分解主要由 C 数据承担；Q3 最优解经桥接后最多形成受约束的反事实能力情景，不反向证明历史因果贡献。

# 4 Q1 Integrated Framework

**Layer 1 — 信号预处理（CONFIRMED FACT + DATA_AUDIT_REQUIRED）**：22 指标统一为“越高越好”是题面硬要求。先按指标定义确定方向，再审计缺失、异常和 8 个列表型字段的压缩规则；尺度参数必须从规定训练/校准样本取得并固定，不能借 A6–A11 Loss 调好指标后还称其为盲测。Opus 的“负号或倒数”不是统一安全规则：倒数在零附近不稳，z 分数可为负且无上界，不能直接当 Q3 所需 (0,1] 质量尺度。任何后续有界标定都须保持顺序并报告参考样本和外推时的截断。

**Layer 2 — 结构与冲突分析（CANDIDATE）**：检查指标相关簇、冗余、域别分布和多维列表字段内部一致性。冲突先在样本层定义，再按域聚合；候选量化口径包括同方向标准化信号的稳健离散度、预先定义的语义对立指标组之间的排序反转、及潜变量残差异常。高教育价值与高广告含量在原始指标上的并存可以是题面示例，但完成“越高越好”变换后须重新解释方向。冲突阈值应来自审计后参考分布、测量误差和扩展集复现，不在此填任意常数。

**Layer 3 — 综合质量表示（DATA_AUDIT_REQUIRED）**：比较顺序为：① 指标方向/尺度固定后的等权或预先分组等权，作为可解释 baseline；② 若强相关结构可重复且成分载荷能与“越高越好”语义对齐，再试潜变量/PCA；③ 下游 Loss 监督赋权仅作有独立训练/验证嵌套和来源配对的预测性替代方案。PCA 的最大方差方向不自动是质量方向，载荷符号和负权重都要检查；用同一 A4/A5 Loss 定权又检验质量对该 Loss 的影响会循环定义。每个评分版本输出样本和域级结果、排序稳定性、覆盖域、映射等级及不确定性，不预定最终算法。

**Layer 4 — 冲突模型（CANDIDATE）**：把冲突评分、疑似来源（真实多目标折衷、指标误差、域移位）、处置规则和处置前后 Q 的变化分开记录。A1 的 content 可作文本核验；A2/A3 缺逐行原文时，必须说明扩展集只做信号层规则复现或找到可证明的原文连接，不把 A18 的另一批文本冒充逐行真值。

**Layer 5 — 17 域配比响应（CANDIDATE）**：p 是已有实验的单纯形向量。加截距的 17 个原始分量完全共线；对比/对数比坐标和稀疏交互是候选，零比例与参考域由实际字段审计决定。Opus 举出的 the_pile_books3 不在已核对 A4 的 17 列，也不在数据说明域名录中，故 REJECTED。四个没有同名验证 Loss 列的训练域仍可影响其余 13 个响应，不应直接丢弃或武断找代理。

**PRIMARY RESPONSE CANDIDATE + SECONDARY HETEROGENEITY ANALYSIS**：若 13 个 Loss 列确实同尺度、同评测目标且无官方权重，预先固定的透明综合指标（例如等权）可作为最简主响应候选；同时必须保留 13 域预测误差和方向相反的影响作为次级异质性分析。若量表或目标权重不相容，多响应/多目标可升为主口径。PCA 综合仅在载荷稳定且解释与任务目标一致时考虑；“相近验证域做代理”缺乏独立依据，当前不作基准。最终主响应和权重保持 DATA_AUDIT_REQUIRED。

## IDENTIFIABILITY_TEST_PLAN_Q1_Q2

设 A4/A5 配对的第 r 个运行有 p_r∈Δ¹⁶，选 16 个独立配比对比构成 P_c，基础设计矩阵 X₀=[1,P_c]；假设有与同一运行 Loss 配对的质量列 Q_r。在线性加性候选 L=X₀β+γQ+ε 中，给定 X₀ 满列秩，γ 的代数唯一性**当且仅当** Q 不在 col(X₀) 中；等价地，残差化列 (I−Π_X₀)Q 非零。若 Q_r=p_rᵀq 且 q 在运行间固定，Q 列在 X₀ 的张成空间内，γ 完全不可识别。检查秩、最小奇异值、条件数和残差化 Q 的尺度，须与 Loss 的测量误差/重复运行精度一起评估；残差非零但极小时是弱识别，只有很窄 p 支持或很少独立运行则是经验覆盖不足。不同于这些统计问题，因果“提高质量”的效应还需要可辩护的外生变化。

- **Path A 优先审计**：A1–A3 是否有能连接到 A4/A5 每个配方运行的质量构成、版本或批次，使相同/近似 p 下 Q_r 有独立变化并观测相应 Loss。仅发现 A1 文本之间 q_i 不同、或同一文本跨域出现，不足以让 A4/A5 获得逐运行 Q_r。检查 id、source path、配方 index、训练数据批次、质量域映射与 Loss 键；若无配对与残差变异，Path A 暂不可用。
- **Path B 作为退路候选**：若 Q 只随 p 确定变化，保留 q 的测量价值与联合配比响应，但不分报独立 γ；p_eff=p⊙q 是编码而非识别修复。需要检查 q_j=0/缺失、是否归一化、域映射误差以及对 A6–A11 的预测稳定性。即使好用，也不能从 A 单独推出“Q 升 0.1 等于增 N 若干”。
- **Path C 作为分级情景**：核对 B6–B8 的 Q_score 生成方式、(N,D,Q) 设计矩阵秩、是否独立扰动 Q、是否与 Q1 质量标尺一致。若条件满足，可估半合成生成过程内的质量项；向真实训练运输仍是额外假设，须与 B1/A 的真实损失和外部文献作敏感性对照，不能升级为真实因果验证。
- **非线性补充**：即便固定 q 时某个非线性 f(p,q) 列不在简单线性 p 的列空间，也只是靠函数形式获得统计辨识；若没有独立 q 变化，跨质量水平的运输仍无法由 A 实验验证。不能用更复杂函数隐藏这一点。

本计划的第一结果不是“选 Path B”，而是给出每条路径的字段存在性、配对证据、秩/弱识别诊断和可允许的论文措辞。

# 8 Q3 Integrated Framework

**变量合同**：在题面代理问题中，N、D、Q 可作为候选连续决策变量，但各自上下界、Q0 的同尺度定义及是否存在可行预算仍待审计。p 的可选层级为：上游已验证配比/少数候选固定；在观测支持域附近用低维参数化或局部变化；只有 Q1/Q2 预测在足够广的 simplex 区域通过验证，才考虑 17 维联立优化。训练、质量和注意力成本使用同一 D。L_ctx 是 C7/任务给定的**外生情景量**，绝不成为内点寻优变量。

**成本合同**：题面给 C_train=6ND，C_Q=D[g(Q)−g(Q0)]_+，C_attn=ηNDL_ctx；g 的指数、幂、对数渐进三类必须比较。N 与 D 应用原始个数/token，不能把表中“十亿”数直接代入。三类 g 的参数虽然题面列明，是否能与 Q1 的质量尺度和 C 预算产生合理数量级仍须检查；必要时只把超出可行域的结果报告为模型假设不适用，而非暗中改系数。

**p 的外推保护**：A4 配方凸包是可选的经验支持限制，不是题面硬约束，且高维凸包可能过窄或难计算；也可使用审计后定义的局部信赖域/候选配比集合。需先证明限制来自数据覆盖或现实供给，而非为了制造内点。Opus 的 ε=0.05 未说明距离、尺度、误差或校准方式，REJECTED 作为固定阈值。若候选最优 p 位于支持边界，报告边界和内部替代解的性能/成本差；若离开支持域，仅作外推情景。

**PROVISIONAL ANALYTIC THRESHOLD**：由题面代理式，N,D>0 时 C_attn/C_train=(ηNDL_ctx)/(6ND)=ηL_ctx/6；η=2×10⁻⁴ 给 L_ctx^crit=6/η=30,000 tokens。代数与题面常量确定，量纲上 η 必须按每 token 的代理系数解释；“30,000 是否是本题可行或经验上重要的长度”仍需 C7_AUDIT。固定 L_ctx 时两项比值与 N、D、预算 C 无关，故不能声称预算增加导致训练成本转向注意力成本。即使 C7 可行长度低于 30,000，注意力项也不自动可忽略，须报告实际代理比值并与质量成本一起比较。C7 的架构上限与真实训练上下文也可能不同。

**预算网格**：题面示例是 10¹⁹、10²²、10²⁴ FLOPs，并允许其他至少三个不同量级。Opus 的 10²¹/10²²/10²³ 可记为 INITIAL CANDIDATE GRID；正式网格须先核可行解、上游支持域和可能转移区间。不能为了出现“结构性转移”事后挑预算点。

# 9 Structural Transition Definition

先固定成本族 g、外生 L_ctx、经过核验的损失模型及可行域，定义最优解集 X*(C)。若唯一且稳定，可跟踪非平凡活跃约束集 A(C)：Q=Q0 投入开关、p 的零/上界或数据支持边界、N/D/Q 实际上下界等；预算约束若所有方案都活跃，本身不构成转移。

**Primary Definition（WORKING HYPOTHESIS）**：在某预算附近，经过数值容差和上游参数不确定性检验后，最优解的非平凡活跃制度发生稳定变化，例如从 Q=Q0 转为 Q>Q0，或 p 支持集合、N/D 边界状态改变。若解不唯一，以最优解集的制度变化而非单点路径判断。只有连续平滑调整而无制度切换时，应报告“未检出此定义下的结构转移”。

| Opus 候选判据 | 本轮地位 | 原因与所需验证 |
|---|---|---|
| A 活跃约束集变化 | Primary 候选 | 可给 KKT/互补性条件并数值核对；排除永远活跃的总预算约束 |
| B 边界 ↔ 内点 | A 的特例 | 数学清晰，但若所有真实最优都在边界，不应硬造内点 |
| C 资源份额/弹性变化 | Supporting Indicator | 连续变化未必是结构切换；须事先定义幅度相对数值和参数误差 |
| D 主导边际投资排序变化 | Supporting Indicator | 受导数估计与不可识别质量效应影响，需不确定性区间 |
| E d x*/d log C 显著变化 | Supporting Indicator | 需要解路径平滑且稳定；折点可能是求解器或网格伪影 |

验证时扫过连续预算区间，比较三类 g、上游参数区间与 C7 可行 L_ctx；分别记录成本分项、活跃集、目标误差和解的支持域。解析推导适用于可微内点/简化边界，非凸或正部成本折点可用分段条件和数值核验；本轮不选求解算法。

# 11 Q4 Integrated Framework

**能力与筛选**：从 C1 或 C2 与 C8 对账，定义固定任务集合、六维综合方式和逐任务异质性；C3 的不同时期评测口径必须核对，C4 连接模型名、训练算力/数据、开源权重，区分 pretrained 与 chat/finetuned。开放口径至少区分可下载权重与许可证可研究/复现；主口径确定后做替代筛选敏感性。C1/C2/C9、C5/C6 的重叠不得重复当独立样本。

**时间起点**：不凭比赛日任意设 t=0。先在 C1/C2/C3/C4 核查提交、公布、版本日期的缺失、滞后和先后关系，选一个在预测时可用且可复核的主时钟；预测窗口从冻结的最后可用观测/截止日期起算，另做日期替代敏感性。具体 t=0=DATA_AUDIT_REQUIRED；若题面或提交口径要求未来 12/24 个月相对比赛时点，还需说明数据末端至比赛时点的空窗如何处理。

**贡献分解候选**：设同一能力定义下的条件预测函数 F(S,T,Z)，S 是预先定义的规模变量集合，T 表示非规模时间/技术状态，Z 是模型类型等控制。对 t₀→t₁，可用两种变化顺序的平均构造描述性 Shapley/Oaxaca 型“规模部分”和“剩余条件部分”；前提是反事实组合落在共同支持域，交互分摊规则公开。透明回归/趋势分解作为 Baseline；Oaxaca 型、模型族面板/固定效应、前沿/时间效应为 Candidate；状态空间只在可比时序足够时考虑。若用 C≈6ND 同时把 log N、log D、log C 无约束放入线性回归，则 log C≈log6+logN+logD，规模系数无法分开；须选不重复的尺度变量并审计真实 C 的独立变异。

“非规模技术进步”暂定义为**在固定已测规模、类型和时间口径后，能力边界/条件均值中未由规模解释的变化**，可含架构、数据工程、对齐，也可能混入遗漏变量、评测改变和选择效应；没有识别设计时只称“条件非规模部分/残差趋势”，不称纯技术因果效应。不得将 Q/p 同时计入规模与非规模而重复分摊。能力前沿与 12/24 月区间需针对开放模型候选池、分数天花板、C3 混合口径、算力放缓情景和桥接误差分别做敏感性；正式预测模型暂不定。

# 12 Evidence Hierarchy

| 层级 | 可放入的证据及其主张范围 | 明确不能推论 |
|---|---|---|
| Level A 直接真实观测 | A1–A3 质量信号、A4–A11 配比/真实 Loss、B1 Pythia 轨迹、C1/C2/C4/C8 等各自在其测量环境中的事实 | “都是真实数据”不代表 A/B/C 验证集、模型类型或 Loss 相互可比 |
| Level B 经审计可比的跨源证据 | B4/B5 中通过家族/验证集审计的部分，C5/C6 中高可比且覆盖相关规模的部分；可用于指定子群的外部检验/桥接 | 未审计的全表不自动升 Level B；近邻重叠不是独立外部验证 |
| Level C 真实规律校准的半合成/派生辅助 | B2、B6–B8 可用于假设情景、程序压力测试及半合成设计内参数估计；B3 是插值派生，另标记 INTERPOLATED | 不写成真实训练实验直接观测；不单凭此声称真实 Q 弹性或因果质量效应 |
| Level D 模型估算、远端外推和未来情景 | A13/A15、B10、Q3 高预算配置预测、Q4 未来前沿 | 不能拿模型生成数回头证明同一模型；必须给适用域、假设和误差 |

数据性质和可比性是两条轴：例如 C5/C6“混合”须逐行按 Loss_Comparability 分层，不能给整张表一个统一等级。若质量系数 γ 主要来自 B6–B8，论文应写“在基于真实规律校准的半合成补充数据中，质量修正呈现……；真实训练数据中该系数尚缺独立检验”，并给情景范围，不报成实测质量贡献。

# 14 Candidate Innovations

1. **冲突感知质量表征（CANDIDATE）**：若透明平均掩盖语义冲突，引入可重复的冲突量与域级不确定性；须在 A2/A3 扩展域及可核原文中比 baseline 稳定，失败就回退。
2. **simplex 可行交换和跨规模配比机制（CANDIDATE）**：若普通配比线性响应在 A6–A11 失效，引入受限交互或多响应，比较域交换解释与留出误差；无增益不加复杂度。
3. **跨源的分级广义标度关系（CANDIDATE）**：显式标出真实识别、半合成情景和不可识别交互，让 Q3 吃到带范围的函数，而非伪精确一体化系数；若桥接标定失败，保留分块结果。
4. **结构转移的制度定义（CANDIDATE）**：把活跃约束变化与预算/成本/参数扰动结合，比较于简单“画弯曲线”基准；若不稳定，如实报告未发现可靠转移。
5. **可比性分层的 Loss–Benchmark 桥接（CANDIDATE）**：在高可比层建立能力区间并测试运输到其他类型；若失败，保留 Q4 独立历史分解与前沿预测，不制造 Q3→Q4 数值闭环。

这些都不是已实现创新；每项必须能回答“基准缺陷—新增数学结构—所需数据—真实验证—失败放弃”后才进入论文创新陈述。

## ROUND 5 P1 PREREGISTRATION CONTRACT

这些规则现已设计，但具体数值容限、最终权重、变量集合和桥接等级仍需在相应数据审计后、正式拟合或查看保留集前冻结。P1 的“已转成任务”不等于实测通过。

**P1-1 — 13 域 Loss 主响应权重。** 预注册三条候选：A 为原始 13 域等权算术均值，仅在同一交叉熵口径/尺度可比时有效；B 为只用 A4/A5 训练部分计算各域中心/尺度、冻结后求等权标准化均值；C 为训练部分提取的低维/PCA 综合，仅在载荷稳定、方向可解释时启用。所有方案都保留 13 维 DOMAIN HETEROGENEITY ANALYSIS；A6–A11 只能检验已冻结的方案，不能反向调整权重。主口径选择按训练期预定用途、可解释性、来源一致性和保留集误差相对基准的稳定性做审计后决策，不设随意固定的异质性触发线。

**P1-2 — Strong/Weak/No Bridge。** GATE 4 前登记高可比层的独立模型族、Loss_Source、模型类型、验证语料/tokenizer、Q3 预测 Loss 与 N/D/Q/p 的覆盖；随后冻结同一留族/留时拆分上的基准映射、方向一致性、任务级异质性、预测区间校准及桥接误差相对 Q3 情景变化的比较规则。Strong 需可比且覆盖、增量映射稳定且区间足以分辨所声称的能力差异；Weak 为有限子群稳定但误差/运输限制强；No 为方向冲突、覆盖不足或样本外无可用信息。独立家族数、RMSE、覆盖率的具体容限须依有效簇与基准噪声在看保留结果前校准，不能照抄 Verify 稿未经校准的固定示例值。

**P1-3 — p 的现实供给。** 审计 A4/A6–A11 的经验支持、各域可观测上下界与极端配方；另查来源许可、数据总量、可再采性及质量稳定性，未核实的供给约束只能标情景。Q3 预注册比较完整 simplex（理论解）、A4 支持域/凸包（数据内解）、经校准的局部扩展（外推情景）、有外部依据的域供给界（可实施候选）。每组都报告约束来源、预算可行性、边界位置与最优值差。若供给证据不足，仅报理论/数据支持解，不称可实施最优。

**P1-4 — Q4 规模变量。** 建模前按理论含义、C4/C1-C3 匹配覆盖、时间完整性和设计秩选择主变量集合，再看能力结果；候选为 (log N,log D)、单一 log C，或在可识别时 log C 加不重复的形状变量如 log(D/N)。若 C≈6ND，log C≈log6+logN+logD，不能把三者作为可分系数同时无约束放入同一线性式。实际 C 可偏离代理式，须审计这种独立变异及缺失机制；其他规模定义用相同样本作稳健性分析。规模贡献指选定变量集合的**联合条件贡献**，不强行分摊不可分的 N/D/C。

**P1-5 — 非平凡约束与 Q3 验证。** Primary 转移只看预先定义、固定且有数据/工程依据的约束制度在预算扫掠中稳定改变；预算约束若始终活跃不算转移，若因真实饱和而从活跃变松弛则可报告。一个固定、可信的 N 上界在跨预算时转为活跃也可能是有意义的边界制度；不能用“是否随预算单调变化”机械排除。随预算人为移动的边界或由求解器容差造成的开关不算机制。Q3_VALIDATION_PLAN 必须检查单变量极端集中、零质量投入、p 角点、人工边界、近等价多解、微小参数扰动跳变、KKT/约束残差和支持域；若无稳定制度变化，报告未发现此定义下的转移。

**P1-6 — Conservative Story 最低完整性。** 即使独立 Q 效应、Strong Bridge 和高维 p 优化都失败，仍必须：Q1 用 A1–A3 全量完成可解释质量/冲突及 A4–A11 有检验的配比关系；Q2 按题面用 B1、B2 或 B3、B4/B5 与 B6–B10 的分级证据，给包含 Q/p 的**条件**广义关系和局部弹性/替代边界，不把半合成系数称真实估计；Q3 至少三个不同量级预算、三类成本比较、C7 可行 L_ctx/解析阈值及可行配置，允许报告无稳健转移；Q4 用 C1 或 C2、C3、C4、C8 做分层能力贡献与 12/24 月区间，并按 C5/C6 或可靠文献尝试 Loss–Benchmark 映射及误差分析。若可靠桥接失败，明确报告映射不可运输及与资源链只保持弱概念连接；这可能是题面强定量连接的**部分未达成**，不能宣称完整定量闭环。若必用数据未处理、Q1 留出无有效关系、Q2 基线系统失配、Q3 不可行或 Q4 核心资料无法用，须返工相应问，不把“保守版”当跳过要求的许可。

# 20 Answers to Opus Six Questions

**1. Q1 质量评分权重优先级。** 先用方向/尺度审计后透明的等权或预先分组等权作 baseline；只有相关结构稳定、潜变量语义和正向性可解释，才比较 PCA/latent；下游 Loss 监督权重只在样本/来源隔离、嵌套验证与“测量 Q”对“预测 Loss”不循环时作为替代。z 分数若出现负值，必须经冻结的有界映射才可进入 Q3。最终权重 DATA_AUDIT_REQUIRED。

**2. Q1→Q2 的 Q 形式。** 原始合同应同时保留域级 q、映射等级、p 与评分误差；A 独立标量、B 域向量、C 联合 p⊙q、D 情景修正分别在 §5 比较。固定 q 的 C 只重编码 p，不能同时声称独立质量导数；若 Path A 无配方级独立质量变化，优先讨论联合响应加半合成/文献条件质量情景，但不能提前 CONFIRM Path B。

**3. B6–B8 的论文措辞。** 统一写“基于真实观测规律校准的半合成补充数据”。可以说“在所设半合成机制下质量参数/响应表现为……，并用于条件敏感性分析”；不能说“真实训练实验直接观察到质量提高导致……”。若 γ 主要据此估计，Q3 中 Q 的边际投资也是情景或区间，实际数值尚未计算。

**4. Q3 预算网格。** 题面示例 10¹⁹、10²²、10²⁴ FLOPs；Opus 的 10²¹/10²²/10²³ 可列 INITIAL CANDIDATE GRID，非已选方案。先用实际 N/D 原始单位、三类 g 与可行域核算，再预注册覆盖低/中/高且可能跨越机制变化的预算；不得看见想要的转移后再挑格点。
