# 2 P0 BLOCKERS

## P0-1：秩检验计划的输出解释不完整

**位置**：§5 IDENTIFIABILITY_TEST_PLAN_Q1_Q2

**问题**：
整合稿正确给出了秩检验的代数条件：
> 若 Q_r=p_rᵀq 且 q 在运行间固定，Q 列在 X₀ 的张成空间内，γ 完全不可识别。

并提出检查"秩、最小奇异值、条件数和残差化 Q 的尺度"。

但**缺失关键决策规则**：

1. **完全秩亏时**：残差化 Q 数值为零（或 < 机器精度）→ 明确结论是什么？是"禁止独立 Q 效应"还是"Path A 失败，进入 Path B"？

2. **弱识别时**：残差化 Q 非零但"极小"的量化标准是什么？相对于什么尺度判断"极小"？是相对于 Loss 的测量误差，还是相对于 Q 的原始标准差？

3. **经验覆盖不足时**：p 支持域很窄或独立运行很少，即使秩满也可能无法稳健估计 γ。这与秩亏/弱识别的区别在哪里？输出措辞如何不同？

4. **Path A 可行时**：若残差化 Q 显著非零且有足够覆盖，Q2 的具体建模形式是什么？是 L = X₀β + γQ + ε，还是更复杂的交互？

**为什么是 P0**：
数据审计的第一批（P0-1）将执行秩检验，但如果审计团队拿到 `cond(X₀) = 1e15` 或 `||(I−Π)Q|| = 1e-8` 这样的数值，**当前整合稿没有告诉他们应该输出什么结论**，以及该结论如何传递到 Q2 建模。

这会导致审计结果无法被后续建模消费，必须回头补决策树。

**所需补充**（在进入审计前）：
在 §5 末尾或 §15 GATE 1 中增加：

```
IDENTIFIABILITY_TEST_OUTPUT_DECISION_TREE

IF 秩检验结果：
  CASE 1: rank([1, P_c, Q]) == rank([1, P_c]) 
    → Q 在 col(X₀) 中，完全不可识别
    → OUTPUT: "Path A FAILED - No independent Q variation"
    → Q2_ACTION: 使用 Path B（联合 p⊙q）或 Path D（半合成情景），
                  禁止报告独立 ∂L/∂Q

  CASE 2: rank 满秩，但 ||(I−Π)Q|| / ||Q|| < δ_weak 
          （建议 δ_weak = 0.05，或相对 Loss 噪声校准）
    → 弱识别
    → OUTPUT: "Path A WEAK - Q variation exists but limited"
    → Q2_ACTION: 估计 γ 但给宽置信区间；
                  敏感性分析中比较有/无 Q 项

          但有效运行数 < n_min（建议 n_min = 20）
    → 经验覆盖不足
    → OUTPUT: "Path A DATA_INSUFFICIENT - identifiable but underpowered"
    → Q2_ACTION: 估计 γ，标注为 TENTATIVE，

  CASE 4: 满秩、显著残差、足够样本
    → Path A 可行
    → OUTPUT: "Path A FEASIBLE - independent Q effect identifiable"
    → Q2_ACTION: M1 中加入 γQ 项，检验显著性与稳定性
```

**验证方法**：

## P1-5：结构性转移的"非平凡"约束需要具体化

**位置**：§9 的 Primary Definition

**问题**：
整合稿提出：
> 非平凡活跃约束集 A(C)：Q=Q0 投入开关、p 的零/上界或数据支持边界、N/D/Q 实际上下界等；预算约束若所有方案都活跃，本身不构成转移。

**"预算约束不构成转移"这一排除规则正确**，但**其他约束的"非平凡"判据不清晰**：
- N/D 的实际上下界：若 N ∈ [1e6, 1e9]，最优解在 N=1e9（上界）是否算"边界约束活跃"？
- 若所有预算下最优解都是 Q=Q0（不投资质量），这算"制度不变"还是"Q=Q0 制度持续"？

**为什么是 P1**：
若判据不清晰，Q3 可能报告虚假转移（"预算从 10²¹ 到 10²² 时，N 从上界跳到内点"，但实际上只是上界本身随预算提高）。

**所需行动**（在 Q3 求解前）：
1. 明确"非平凡"的操作定义：
   - **非平凡约束**：由模型结构/成本机制决定，不随预算单调变化的约束
     - 例子：Q=Q0（质量投资开关）、p 在数据支持边界、N/D 的 Chinchilla 最优比例
   - **平凡约束**：随预算单调松弛的约束
     - 例子：预算约束本身、N 的可行上界随 C 提高

2. 检验方法：
   - 扰动预算 C → C+ΔC，检查约束集合是否变化
   - 若某约束"只要 C 足够大就永远不活跃"，它是平凡的

3. 只有非平凡约束的开/关变化才报告为"结构性转移"

# 5 Q/p IDENTIFIABILITY VERIFICATION

## 5.1 代数诊断的正确性

**KEEP - 完全正确**：

整合稿 §5 的秩条件诊断：
> 若 A16 把固定域质量 q 映射成 17 维向量，且候选有效质量只是 Q_eff(p)=pᵀq，那么在线性配比模型 L=β₀+βᵀp+γQ_eff(p)+ε 中，βᵀp+γpᵀq=(β+γq)ᵀp。仅凭 A4–A15 的配比变化无法分别识别 β 与 γ。

这是**完全正确的线性代数推导**。设计矩阵 X = [1, p₁, ..., p₁₇, pᵀq]，若 q 固定，最后一列是前 17 列的确定线性组合，秩亏 1。

## 5.2 Path A/B/C 的排序与条件

**KEEP - 排序合理**：

整合稿的三条路径：
- Path A：证明 q 不固定（需要配方级 Q_r 与 Loss 配对）
- Path B：承认联合效应，用 p_eff = p ⊙ q（推荐退路）
- Path C：用 B6–B8 半合成识别 γ（条件情景）

**优先级正确**：Path A 优先审计 → 失败则 Path B → 半合成用 Path C 补充。

## 5.3 重要澄清：p⊙q 不能识别独立质量效应

**KEEP - 澄清正确**：

整合稿明确指出：
> 固定 q 时 [p⊙q] 是 p 的确定变换；正 q 下线性列只是对 p 重新缩放，不能识别独立质量作用。
