# 1 Executive View

全题可以形成“质量与配比表征 → 损失关系 → 算力配置 → 能力解释/前沿”的研究链，但四步不是同一批实验的自然延伸。A 的质量信号与配方损失、B 的训练轨迹、C 的能力评测分别采集；每条跨源箭头都要有可检验的口径与不确定性，不能靠把列名拼在一起制造完整样本。

    A1–A3 质量信号 ──→ Q1：质量评分/冲突/域级不确定性 ──┐
    A4–A15 配比与 Loss ─→ Q1：simplex 上的配比效应 ─────┼→ Q2：条件化 L(N,D,Q,p)
    A16 域映射 ───────────→ Q1：7 质量域 ↔ 17 配方域 ───┘       ↑ B1 主拟合；B2–B12 分层验证/补充
                                                              ↓ 可用范围、参数与误差
    C7 上下文可行值 ───────────────────────────────────────→ Q3：预算约束配置与结构转移
                                                              ⇢ Q4：资源情景，仅在能力桥接可信时解释
    C1/C2、C3、C4、C8 ───────────────────────────────────→ Q4：历史能力与非规模项
    C5/C6 Loss–Benchmark 桥接 ──────────────────────────→ Q4：条件映射及误差传播

实线表示题面要求的输入；“⇢”表示额外情景与桥接假设。Q3 最优配置不是历史模型的观测能力。Q4 对“规模扩张/非规模进步”的拆分也不能自动证明 Q3 的最优策略有效。

本轮最需防止的四个断点：① Q1 的质量评分没有可迁移的尺度；② 在固定域质量下，Q 与配比效应可能不可分辨；③ B6–B8 的半合成质量变化被误称为真实实验因果效应；④ 不同验证集 Loss 被当作同一量并直接映射到 Benchmark。四者都会顺流污染后续结论。

# 2 四问数学本质

## Q1：多指标测量、冲突与受单纯形约束的配方响应

- **表面要求 / 数学本质**：把 22 个方向和尺度不同的信号变成可比较的质量表征，定义同文本指标冲突，再估计 17 域配比对 13 个验证域 Loss 的响应。核心是测量有效性、成分数据上的可识别响应、以及两套域体系的运输。
- **输入 / 观测量**：A1–A3 的质量信号；A4/A5 的训练配比与损失；A6–A11 的保留检验；A12–A15 的估算外推表；A16 的参考映射。实际表头抽查确认 A4 为 index + 17 配比列，A5 为 index + 13 验证域 Loss 列。
- **构造量 / 待估量**：指标方向和尺度处理、样本评分、域级质量及其不确定性、冲突强度、跨域映射、配比响应函数与可能的域交互；相应权重/载荷/回归参数均待估。
- **决策量 / 约束**：本问主要是推断，A4–A15 的配比 p 是已给实验设计，并非此刻要重新优化的自由决策；若讨论推荐配比，仅能作为候选情景。p 位于 17 维单纯形，指标经处理须越高越好，A1–A3 必须全量使用。
- **输出 / 评价**：明确 Q 是样本标量、领域向量还是二者兼有；给出聚合与冲突规则、域级结果及 A1 对 A2/A3 对照；在 A6–A11 验证配比预测，并用 A12–A15 讨论模型外推稳定性。不能把 A12–A15 的估算 Loss 当真实保留观测。

## Q2：跨源、部分可识别的广义损失规律

- **表面要求 / 数学本质**：建立含 N、D、Q、p 的广义 Scaling Law，并计算边际效用、弹性及替代条件。真正难点是 A/B 独立实验只覆盖变量的不同切片，完整联合响应的交互项未必可由数据独立估计。
- **输入 / 观测量**：Q1 的质量/配比合同及可信度；B1 的 N、D、val_loss 训练轨迹；B2 或 B3、B4、B5、B6–B10 的分层补充。B1 表头实际含 run_id、N_params_B、D_tokens_B、C_FLOPs_1e21、val_loss 等，B6 含 Q_score 但为半合成。
- **构造量 / 待估量**：共同 Loss 口径、源别偏差、可估的 N–D 基线、质量或配比修正项、函数有效域与参数区间。若要把 Q1 尺度接到 B6 的 Q_score，还需显式校准或只做情景对照。
- **决策量 / 约束**：本问估计规律而不寻优；N、D、Q、p 是模型输入。候选函数需符合定义域、Loss 为验证集交叉熵，并说明是否采用 Q=1 退化到经典式的附加假设；该退化不是题面强制唯一形式。
- **输出 / 评价**：经检验的损失预测关系、参数与不确定性、边际导数、弹性、配比替代/互补及质量与规模的局部等效条件；评价须分组、跨族和外推，不能让半合成数据替真实证据背书。

## Q3：带外生上下文情景的资源配置

- **表面要求 / 数学本质**：在训练、质量提升和注意力开销之和不超 C 时配置 N、D、Q、p，找不同预算的可行最优策略与“结构性转移”。这是带单纯形、边界和上游参数不确定性的约束优化；是否需要混合变量取决于现实可行集。
- **输入 / 观测量**：Q1/Q2 已验证的质量、配比和 Loss 关系，附录 B 的候选 g(Q)，C7 给出的可行上下文长度。L_ctx 是外生情景量，预算 C 是给定约束；成本参数来自题面而非本轮估计结果。
- **构造量 / 待估量**：可行域、Q0 与 Q 的可比尺度、各成本单位、上游系数区间、结构转移的数学判据。若以最小化预测 Loss 为目标，这仍须受 Q2 的有效域和误差约束。
- **决策量 / 约束**：N、D、Q 是候选连续决策；p 可联立优化或由上游固定，尚不决定。L_ctx 不内点寻优；C_train=6ND，C_Q=D[g(Q)-g(Q0)]_+，C_attn=ηNDL_ctx，η=2×10⁻⁴；至少三个不同量级预算，且 p 满足单纯形。
- **输出 / 评价**：逐预算配置、可行性、成本形式敏感性、结构转移定义与证据、注意力/训练成本临界值及 C7 可行区间敏感性。最优值若落在未观测 p 或 N/D/Q 区域，须标明模型外推风险。

## Q4：观测性贡献分解、异质 Benchmark 桥接与前沿预测

- **表面要求 / 数学本质**：用历史模型能力解释规模与非规模进步的贡献，建立 Loss→多维 Benchmark 的可比性分层桥接，并预测未来 12/24 个月开源能力前沿。这里的“贡献”需要反事实定义；纯残差不等于因果技术进步。
- **输入 / 观测量**：C1 或 C2 排行榜、C3 混合时序、C4 算力/数据/开放性元数据、C8 逐任务 JSON、C5/C6 桥接、必要时 C7 架构信息。实际表头确认 C6 有 Loss_Source 与 Loss_Comparability。
- **构造量 / 待估量**：固定口径综合能力、pretrained/chat 分层、开源与日期筛选、模型匹配、规模贡献与未解释贡献、桥接函数和误差、前沿及预测区间。
- **决策量 / 约束**：本问主要解释和预测，没有真实资源决策；算力放缓为情景输入。输出不能越过分组可比性、时间先后和 Benchmark 量表边界。
- **输出 / 评价**：定义清晰的历史分解、逐任务异质性、Loss–Benchmark 条件映射、开放模型前沿与 12/24 月不确定区间；用时间滚动和模型族留出检验，避免“未来前沿”实际借用了未来提交日期的信息。

# 3 Q1–Q4 Input/Output Interface

| 接口 | 最低输出合同 | 非天然连接与必须验证的条件 |
|---|---|---|
| Q1 → Q2 | Q 的定义域/方向/尺度；样本和 7 质量域评分与不确定性；17 域配比 p；A16 映射及覆盖率；配比到验证 Loss 的可用关系；训练/检验/估算标签 | A 质量信号与配方实验不是同一样本；从 7 域映射到 17 域有 inferred 项。Q 可以先保留为领域向量，不能预设单一 Q_eff。若 Q_eff 由 p 与固定域质量线性合成，单独的“质量效应”可能与 p 效应不可识别。 |
| Q2 → Q3 | 经验证的 L(N,D,Q,p) 或受限分块关系、参数区间、预测误差、可微范围、训练数据支持域、边际效用/弹性及局部替代条件 | B1 无显式可变 p/Q，B6–B8 的 Q 变化是半合成。若完整函数只在强假设下成立，Q3 应使用情景/稳健区间而不是唯一“真”函数。 |
| Q1/Q2 → Q3 | 可比的 Q0、Q 的尺度；p 的可行支持；Loss 目标与成本单位 | Q1 的评分必须可代入题面 Q∈(0,1]；p 没有直接成本项时，数学优化可能把 p 推到数据支持外边界。 |
| Q3 → Q4 | 算力预算和配置情景、预测 Loss 区间、模型适用域及与 C 元数据可匹配的 N/D/类型 | 最优配置是反事实情景，不是 C 中真实模型观测。只有经 C5/C6 或可靠文献校准的可比 Loss–Benchmark 桥接，才可解释其能力含义；Q4 的历史分解本身主要由 C 数据识别。 |
| C5/C6 → Q4 | 高/中可比桥接子集、Loss 来源、Benchmark 维度、映射残差及预测区间 | 不同验证集、tokenizer、任务和模型类型的交叉熵不自动同量纲；应先分层，再决定能否池化。 |

局部“质量提升 ΔQ 等价于扩大参数 ΔN”的候选定义须固定 D、p 和比较基点。若两项改动相对同一基点取得相同 Loss 降幅，一阶关系是 ΔN_equiv≈(∂L/∂Q)/(∂L/∂N)·ΔQ；两导数若均为负，等效参数增加为正。若问题改成“提高 Q 同时减少 N、保持 Loss 不变”，则 dN/dQ|L=−(∂L/∂Q)/(∂L/∂N)，符号相反。两种问题不能混写；导数来自最终经验证函数后才能数值化。

# 6 Identifiability and Assumptions

## 6.1 Q1 的质量、配比与目标口径

Q 应先满足方向一致、尺度可比较、对指标冗余不重复计权、域聚合可追踪、异常和冲突可解释、映射不确定性可传递等性质。若样本级加权评分的权重来自同一批配方 Loss 的反向调优，再声称它独立测量“教材质量”，会产生目标泄漏；可先用质量指标本身建立评分，再以外部/留出标准检验其预测价值。冲突不宜固定为任意两项原始分差：需在同方向同尺度上定义，区分测量冲突（高教育价值同时高广告等）、域偏置和文本类型差异，并比较样本层与域层聚合前后的发生率。A2/A3 无 content，冲突规则可在信号上复算，文本语义核验须另寻可合法对齐的样本。

配比 p 的 17 分量和为 1。带截距的普通回归若同时放入 17 个原始分量必有线性依赖；某域比例增加必从其他域拿走份额，“单域边际效应”必须指定被挤出域或明确的交换方向。对数比/对比坐标能处理闭合效应，但零配比需要预先定义可追踪处理；高阶交互更需稀疏化并在 A6–A11 检验。13 个验证域 Loss 与 17 个训练域比例并非同维，采用逐域多响应、固定权重综合或多目标方案前须说明评测目标权重来源。

更尖锐的不可识别性：若 A16 把固定域质量 q 映射成 17 维向量，且候选有效质量只是 Q_eff(p)=pᵀq，那么在线性配比模型 L=β₀+βᵀp+γQ_eff(p)+ε 中，βᵀp+γpᵀq=(β+γq)ᵀp。仅凭 A4–A15 的配比变化无法分别识别 β 与 γ；p 的闭合还使截距与全部 p 系数不同时可识别。只有独立质量变化、强而可检验的结构约束或外部证据，才可能支持单独的质量效应。Opus 请重点攻击这一点。

## 6.2 Q2 的跨源共同规律

B1 的多行来自少数 Pythia 模型训练轨迹：N 在同一 run 内固定，D 随训练推进；相邻检查点高度相关。必须按 run、规模和时间结构留出，不能用随机行拆分夸大泛化。B1 无独立变化的 Q 或 p；A 的配比实验与 B1 又不是同一模型族/验证集。B6–B8 提供 Q 变化，但半合成生成机制可能预置某种质量效应，不能当真实识别来源。

因此完整 L(N,D,Q,p) 的交互，例如 Q×N、Q×p、p×N，并非“列都存在就能估”。需写清哪些参数由 B1、A4/A5、半合成 B6–B8 各自识别，哪些只在共享参数/可分离性/可运输性假设下成立；比较允许不同源截距、尺度和验证集偏差的候选。若无真实 Q 变化，报告质量效应的条件区间或情景，不给伪精确点值。可选的 Q=1 经典退化应被视为额外形状约束，先说明 Q=1 是否有可解释且与 Q1 同尺度的含义。

弹性须按 ε_N=(N/L)∂L/∂N 等定义，不能把原始有限差分当弹性；若研究“Loss 改善”可另定义对可约损失的弹性，并说明不可约项 E 的不确定性。域互补/替代也应在 simplex 的可行交换方向上定义，不把普通偏导或相关系数当机制证据。

## 6.3 Q3 的成本和解结构

按题面代理式，在 N,D>0 下 C_attn/C_train=ηL_ctx/6，所以两项相当的解析阈值是 L_ctx^crit=6/η=30,000 tokens。这个数来自题面常量的代数计算，不是 C7 的观测结论；阈值是否落在 C7 可行范围内是 DATA_AUDIT_REQUIRED。总成本可写为 D[(6+ηL_ctx)N+[g(Q)-g(Q0)]_+]，便于核对量纲和预算可行性。三种 g(Q) 的参数尺度需与 N、D 的原始单位一起检查，不能直接把以“十亿”为单位的表列值代入 6ND。

在平滑、内点且预算约束活跃的候选模型中，条件一阶式为 ∂_x L+λ∂_x C=0（x∈{N,D,Q}）；这只是一种分析工具，不保证本题最优解为内点。Q=Q0 有正部成本折点，p 在 simplex 边界，N/D 上下界和可能非凸的 Loss 都可导致边界或多局部解。若 p 不直接进入成本，完全自由的 p 可能被预测误差推向未训练角点，须以数据支持域与领域资源现实约束检验，而非为得到漂亮内点随意加罚项。

“结构性转移”应先定义可复核判据，例如最优解活跃约束集合、是否启动质量投入、p 的支持集合、预算弹性或配置比例的分段变化，并区分连续平滑调整与真正的机制切换。预算网格与三类成本、上游参数区间及 C7 情景都要复检；仅看一张曲线出现弯折不足以宣称临界相变。

## 6.4 Q4 的解释边界

若把 Benchmark 增长中不能由参数和算力解释的残差一律命名为“非规模技术进步”，会混入数据质量、领域配比、架构、训练/对齐、评测污染、模型筛选和榜单口径变化。首先定义规模项包含 N、D、C 中哪些量，Q/p 属规模外、数据工程还是单列通道；然后给出条件反事实分解。没有外生冲击或充分控制时，写“解释性贡献/未解释趋势”，不写因果份额。

时间轴可用发布日期、提交日期或版本日期，但必须全程一种主口径，并对滞后/早于公布的记录做敏感性分析。pretrained 与 chat/finetuned 混合会把对齐收益误归给预训练规模。C8 逐任务聚合应检验综合分是否掩盖六维差异；前沿最大值还受候选模型数量增长、选择偏差与分数天花板影响。C5/C6 的 Loss 来源和高/中可比标签要先审计，再讨论单调、分任务或分模型族映射；桥接不确定性须进入 12/24 月区间。

# 10 Research Execution Plan

研究顺序以风险与依赖为主，而不是机械写完 Q1 才打开 Q2。此处是后续团队计划，本轮没有执行数据审计、建模或实验。

1. **先锁事实与口径**：核对题面 DOCX 内嵌公式、原始文件哈希和必用清单；建立训练/检验/估算/半合成的文件级角色表，定义 Loss、单位、日期与综合能力的候选口径。优先消除会污染全题的 R1–R4。
2. **数据审计可分支并行**：A 支路流式盘点全部质量信号并检查指标方向/列表字段，另支路核对 17 配比×13 Loss 的 index 和保留集；B 支路核对 run_id、真实/半合成/插值与 Loss 口径；C 支路先核对榜单、元数据、桥接与 C8 可解析性。并行只适用于相互独立的审计工作，最终字段字典须统一。
3. **理论可先推导但不拟合**：simplex 可行交换、质量与 p 的秩问题、局部质量—规模等效式、Q3 成本比与边界条件、Q4 贡献反事实定义和桥接误差传播。这些推导可在数据审计进行时准备，是否采用需等证据。
4. **基础代码可先搭契约**：只建立流式读取、ID 配对、单位转换、数据版本/哈希、配置与留出划分骨架；避免在没确定响应量与模型规格前写死算法。大文件不一次性全量入内存。
5. **先完成有独立证据的基线**：Q1 质量评分与配比响应两条支线分别验证；Q2 的 N–D 基线可与 Q1 同时评估，因为 B1 不依赖 Q1。C 的模型筛选、C8 逐任务聚合与桥接可比性审计也可并行。Q1→Q2 的合并必须等 Q1 尺度/映射与 B1 基线都过门槛。
6. **再决定联合机制**：按真实留出表现和识别条件筛掉不能估的 Q/p 交互；没有真实质量变异时，明确只做条件情景或部分识别。Q2 有足够误差与适用域后才让 Q3 计算，不能只取最优拟合曲线。
7. **Q3/Q4 分流后会合**：Q3 成本可行域与临界值先解析，正式配置等 Q2；Q4 的历史能力分解可先由 C 数据独立建立，但 Loss–Benchmark 桥接合格后才讨论前三问情景的能力含义。
8. **第一次完整验证时间点**：每个基准一有真实输出即做本问留出；在 Q1/Q2 基线、Q3 可行配置、Q4 桥接与历史模型各有版本后，进行一次跨问追踪检查：输入哈希→模型版本→运行→误差→有效范围→论文可引用结果。失败即回退相应上游，不先写结论。
9. **论文工作**：现在只维护结构与符号表；正式结果、图表和摘要必须等待 VALIDATED 登记。后续高阶路线只有明确修复基准缺陷并通过验证时才进入正文。
